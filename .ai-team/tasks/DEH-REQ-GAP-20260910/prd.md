# 数智产品展厅需求差距补齐完整范围 PRD

## 1 产品目标和目标用户价值

本任务以既有 46 项需求完成度矩阵作为唯一范围台账，完成当前 Vue Web 仓库能够独立闭合的全部页面、交互、状态、接口接线、安全门禁和自动化验证缺口；对必须由甲方、飞书、EAD、RPA、机器人、监控平台或生产运维提供输入的能力，保留在同一任务中，先完成仓库内可并行部分，待输入到位后继续完成 Web 接入和端到端验收。执行分批只表示先后顺序，不缩减范围，也不产生“后续是否纳入”的二次范围决策。

目标用户包括普通用户、业务开发人员、应用负责人、内容管理员、部门管理员、平台管理员和技术运维人员。目标价值是：用户在 remote 模式看到权威数据及真实权限结果，不再把 fixture、本地状态、测试审批或 `TEST_` 写入误认为生产结果；管理员能够区分已交付、可验证阻塞和待外部输入的能力；工程与 QA 可以按同一矩阵判断完整任务是否完成。

“全部完成”定义如下：

1. 46 项中所有可由当前仓库闭合的工作均有页面或服务行为、关键状态和自动化证据。
2. 所有外部依赖要么已解除并完成正式账号、正式数据或外部系统的端到端验收，要么继续以具名外部阻塞保留，且不得表述为已交付或生产完成。
3. `npm test`、完整 `npm run test:integration`、`npm run build` 均以 exit code 0 通过；当前 REG-001 必须修复。
4. 合同存在、服务端可读、单个测试通过或生产构建成功，均不能单独证明目标页面或生产业务闭环完成。

### 2.2 判定口径

| 当前基线 | 判定规则 |
| --- | --- |
| 已完成（仓库技术项） | 在明确限定的仓库技术责任内已有可执行行为和当前证据，不以此推导生产业务域完成。 |
| 部分完成 | 有页面、合同、服务或测试基础，但仍混有 fixture、未消费真实数据、缺关键动作/状态，或只形成测试闭环。 |
| 未完成 | 只有静态 UI、数据结构或占位说明，尚未形成要求的行为。 |
| 外部阻塞 | 缺少正式接口、账号、规则、数据、回调或部署能力；仓库内可先完成的适配和阻塞态仍属于本任务。 |

只有同时满足以下条件，业务项才可改为“已完成”：目标页面消费真实数据或真实接口；remote 模式不以 fixture 或固定值回退为成功；服务端执行身份、权限和数据范围校验；加载、空、错误、未登录、无权限及适用操作状态有证据；若涉及外部系统或正式写入，必须有正式环境端到端证据。

## 4 主要用户流程

### 4.1 普通用户真实读取与使用流程

1. 用户从海能Work或 Web 入口进入展厅；系统建立正式用户会话并加载角色、组织和数据范围。
2. 用户进入应用、素材、培训、人才、认证、积分、公告或消息页面；页面通过统一 operation 能力合同请求安全投影。
3. 请求期间显示加载；成功时只显示权威数据；零记录显示空态；失败、未登录或无权限时显示可恢复状态，remote 模式不回退 fixture。
4. 用户进入详情或触发下载/使用；系统在服务端校验身份、权限、文件或目标地址允许范围。
5. 允许时返回最小字段或短时同源地址；拒绝、缺文件、不可达或超时时保留上下文并提供可理解的下一步。
6. 涉及正式申请、收藏、评论、报名、已读或预约时，若正式写合同尚未到位，页面明确禁用/阻塞且不模拟成功；到位后按幂等、版本、审计和失败回滚完成。

### 4.2 管理员与运维流程

1. 管理员进入应用、公告、配置、日志或运行监控页面，服务端按角色和数据范围授权。
2. 只读能力先显示真实列表、详情、日志和状态；不存在的数据展示空态，不展示固定统计或告警数。
3. 写入合同到位后，管理员完成新建、编辑、发布、下线、推荐、排序等操作；系统校验版本、幂等、防重和权限，并记录前后快照及结果。
4. 发生错误或告警时，运维查看脱敏请求 ID、状态和可重试信息；监控平台到位后完成告警分派、处置与关闭。

### 4.3 上架、审批和发布流程

1. 申请人选择应用类型并填写对应类型表单。
2. 系统根据签字责任表选择 RPA、飞书、EAD 或其他审批传输；未配置类型不得伪装提交成功。
3. 提交后展示渠道、实例号、时间和可获取状态；重复提交使用幂等键。
4. 审批通过后只投影一次到应用索引和类型详情；拒绝或取消不得发布。
5. 用户从权威列表进入详情，并按目标系统权限结果直接使用或发起申请。

### 4.4 外部依赖决策点

- 依赖未满足：页面显示“未配置/等待外部输入/无正式权限”等可验证阻塞态，写按钮不可执行，不落本地成功状态。
- 依赖满足：必须执行正式账号、正式权限、正式数据或外部系统的端到端验收；合同测试不能替代。
- 外部调用失败：显示脱敏错误、请求 ID 和恢复入口；不得增加成功计数、已读、收藏、报名、发布或审批成功状态。

## 5 状态清单

| 状态 | 触发条件 | 页面行为 | 数据与安全要求 |
| --- | --- | --- | --- |
| 成功 | 权威请求与必要权限校验成功 | 显示真实结果及明确来源 | remote 不混入 fixture；仅显示安全投影。 |

| 空 | 请求成功但零记录或无关联 | 显示域内空态和清除筛选/返回入口 | 不生成示例记录或固定统计。 |
| 错误 | 超时、上游、schema、服务或操作失败 | 显示脱敏分类、请求 ID、重试或返回 | 不暴露 token、Secret、内部表/字段/文件标识或原始上游响应。 |
| 禁用 | 正式写入、规则或接口未开放 | 控件不可执行并说明缺失输入 | 不调用写 operation，不以本地状态模拟。 |

| 版本冲突/重复 | 写入版本过期或幂等重放 | 提示刷新、比较或返回既有结果 | 不覆盖新版本，不重复发布/发送。 |

## 8 Given/When/Then 验收标准

所有验收证据必须标注矩阵 ID、页面/operation、环境、账号/角色、数据样本、预期与实际。自动化责任方默认为 Web 工程与 QA；外部端到端证据由对应依赖 owner 配合 QA 提供。

### 8.1 应用中心、详情、上架和使用（R02-R17）

**AC-APP-01 权威目录。** Given 运行在 remote 且 APP-001/002 返回正式与测试记录，When 用户进入应用中心并筛选、搜索或分页，Then 页面只按服务端权威投影呈现，不按 `TEST_` 前缀过滤，不混入 `APP_FIXTURES`，零记录显示空态。证据：页面测试、operation 请求断言、浏览器验收；责任方：Web/QA。

**AC-APP-02 九类真实详情。** Given 九类应用各有公共和类型专属投影，When 用户从真实列表进入详情，Then 标题、说明、指标、流程、附件、培训、评论和素材按返回数据呈现，缺失字段为空态，不由硬编码补值。证据：九类参数化组件测试与浏览器验收；责任方：Web/QA。

**AC-APP-03 权限动作。** Given APP-004 分别返回允许、拒绝、不可达或无安全地址，When 用户在列表或详情点击“立即使用”，Then 两处遵循同一结果：仅允许时打开白名单地址，其他情况显示对应状态且不绕过服务端。证据：组件与服务端权限测试；责任方：Web/QA。

**AC-APP-04 依赖未满足。** Given 某类型没有正式审批/写入合同，When 用户尝试提交、更新、下架、收藏、评论或申请，Then 页面显示未配置或禁用，不调用正式写入，不产生本地成功。证据：负向组件测试；责任方：Web/QA。

**AC-APP-05 依赖解除后闭环。** Given D03-D06 已解除，When 各类型分别经历提交、审批通过/拒绝/取消、发布和重复回放，Then 渠道与状态可追溯，通过只发布一次，拒绝/取消不发布，历史与审计完整。证据：每类型正式预发布 E2E；责任方：业务 Owner/外部系统 Owner/Web/QA。

### 8.2 素材（R18-R19）

**AC-MAT-01 浏览与下载。** Given MAT-001/002/003、用户会话和文件权限有效，When 用户进入 `/materials`、组合筛选并下载，Then 页面使用真实分类/素材/关联应用数据，短时同源下载成功，浏览器不获得上游文件令牌。证据：组件、服务端文件安全与浏览器验收；责任方：Web/QA。

**AC-MAT-02 边界。** Given 返回零记录、401、403、无文件、超时或上游失败，When 页面加载或用户下载，Then 分别显示空、登录、无权限、文件缺失或可重试错误，保留筛选且不显示成功。证据：状态注入测试；责任方：Web/QA。

**AC-MAT-03 写依赖。** Given 正式素材写合同未提供，When 用户查看管理动作，Then 上传、编辑、发布、收藏和下架禁用；Given 合同已提供，When 正式角色执行这些操作，Then 版本、幂等、权限与审计均通过。证据：前置负向测试及依赖解除后的 E2E；责任方：内容 Owner/Web/QA。

### 8.3 培训与人才（R20-R22）

**AC-LRN-01 培训真实边界。** Given remote 下 TRN 数据有记录或零记录，When 用户进入培训页，Then 课程、计划、统计、资料和入口来自服务投影；零记录显示空态，不回退固定课程。证据：页面测试和浏览器验收；责任方：Web/QA。

**AC-LRN-02 报名依赖。** Given 正式报名合同未提供，When 用户尝试报名/取消，Then 显示阻塞且无本地成功；Given D03/D09 已解除，When 用户报名、重复报名、取消、遇到满员或无权限，Then 服务端结果、参与记录和页面状态一致。证据：负向测试与正式 E2E；责任方：培训 Owner/Web/QA。

**AC-TAL-01 三页真实接线。** Given TAL-001/002/003 分别返回记录、零记录或错误，When 用户进入人才库、项目和进度页，Then 三页实际消费 operation 结果，并分别显示真实、空或脱敏错误状态，不使用 fixture。证据：三页组件测试和浏览器验收；责任方：Web/QA。

### 8.4 数字化认证（R23-R24）

**AC-CER-01 认证只读。** Given CER-001/002/003 与正式用户会话有效，When 用户进入认证页，Then 规则、项目、场次、个人结果和材料按数据范围显示，加载、空、错误和无权限状态可区分。证据：页面与角色验收；责任方：Web/QA。

**AC-CER-02 申请依赖。** Given 正式认证流程未提供，When 用户点击申请、审核或预约，Then 页面明确未配置且不本地模拟；Given D03/D09 已解除，When 执行申请、审核、预约、取消和结果查询，Then 状态、权限、防重和审计一致。证据：负向测试与正式 E2E；责任方：认证 Owner/Web/QA。

### 8.5 积分（R25-R26）

**AC-PTS-01 完整读取。** Given PTS-001/002/003/004 返回当前用户数据，When 用户查看总览和明细，Then 余额、分类、来源、规则版本和流水全部来自投影，零记录不显示固定余额或静态规则。证据：页面测试与当前用户隔离测试；责任方：Web/QA。

**AC-PTS-02 规则冲突与解除。** Given D10 未解除，When 数据包含负积分方向，Then 页面不宣称满足“只累计”，并显示待规则确认的安全状态；Given签字规则到位，When 提交允许与禁止方向，Then 服务端接受允许项并拒绝禁止项，页面不得乐观成功。证据：规则正反例服务端测试与 E2E；责任方：积分 Owner/Web/QA。

### 8.6 公告与消息（R27-R30、R41）

**AC-ANN-01 公告真实接线。** Given ANN 读取返回列表、统计、详情、附件与关联对象，When 用户浏览、筛选和打开详情，Then 页面消费真实投影，不使用 `ANNOUNCEMENT_FIXTURES`，并覆盖置顶、分页、空、错和文件状态。证据：列表/详情组件与浏览器验收；责任方：Web/QA。

**AC-ANN-02 后台写依赖。** Given 正式公告写合同未提供，When 管理员尝试保存、发布或下线，Then 页面禁用或显示未配置；Given 合同到位，When 完成草稿、预览、发布、编辑冲突和下线，Then 前后台一致并保留版本审计。证据：负向测试与管理员 E2E；责任方：内容 Owner/Web/QA。

**AC-MSG-01 当前用户隔离。** Given 两个正式用户拥有不同消息，When 各自进入消息页，Then MSG-001/002 只返回本人消息、未读统计和安全目标路径；无目标路径不得跳转。证据：正式账号隔离验收；责任方：身份 Owner/Web/QA。

**AC-MSG-02 已读与机器人。** Given正式写或机器人输入未提供，When用户触发已读或通知，Then页面显示阻塞而非成功；Given D03/D07 已解除，When执行单条/批量已读及机器人成功、失败、重试和重复发送，Then状态与发送日志一致且防重生效。证据：正式 E2E 与审计记录；责任方：消息平台 Owner/Web/QA。

### 8.7 运营、后台、权限、日志和监控（R31-R37、R44）

**AC-OPS-01 运营真实数据。** Given OPS 读取对某周期返回数据、零记录或错误，When 用户切换周期或刷新，Then 指标、趋势、排名和时间口径来自真实结果，不用固定数组或数学放大，并正确显示空/错态。证据：页面测试与浏览器验收；责任方：Web/QA。

**AC-ADM-01 后台只读与权限。** Given OAP/ADM/INT/ARC 读取和五类角色矩阵可用，When 不同角色进入后台，Then 页面实际消费真实数据，允许角色只见其数据范围，越权请求由服务端拒绝；不得以隐藏按钮代替。证据：角色矩阵与服务端授权测试；责任方：身份 Owner/Web/QA。

**AC-ADM-02 正式配置写入。** Given正式写合同未提供，When管理员尝试配置、推荐、热门、更新或下架，Then不产生本地成功；Given合同到位，When执行新增、修改、停用、排序、发布、更新和下架，Then前台一致、引用约束、版本冲突和历史审计通过。证据：管理员 E2E；责任方：业务 Owner/Web/QA。

**AC-LOG-01 真实日志。** Given日志读取返回记录、零记录或错误，When运维进入日志页，Then页面显示真实脱敏日志、筛选和请求 ID，不显示 `logRows` 假数据；正式采集合同到位后，成功、失败、重试和权限拒绝均自动留痕。证据：页面测试、故障注入与审计核对；责任方：运维/Web/QA。

**AC-MON-01 告警阻塞与闭环。** Given监控平台未配置，When用户进入监控页，Then显示未配置，不显示固定告警数；Given D08 已解除，When注入可控故障，Then生成告警、通知、分派、处理并关闭，状态和时间可追溯。证据：故障演练；责任方：监控 Owner/运维/QA。

### 8.8 平台、安全、生产网络和数据生命周期（R01、R38-R40、R43、R45-R46）

**AC-PLT-01 生产网络守卫。** Given应用运行在正式 HTTPS 域名，When页面调用同源 API，Then客户端不得因“非 localhost”而拦截；When脚本尝试访问未允许的跨源或目标地址，Then服务端/安全策略拒绝。Given应用运行在明确开发/演示条件，Then本地网络守卫仍按配置生效。证据：环境参数化自动化与预发布浏览器验收；责任方：Web/安全/QA。

**AC-PLT-02 REG-001。** Given P0 修复完成，When执行完整 `npm run test:integration`，Then `feishu-integration-review-remediation.test.mjs` 不再发现 `App.vue` 直接 remote 模式分支，30/30 脚本均执行且总命令 exit code 0。证据：完整未短路日志；责任方：Web/QA。

**AC-SEC-01 凭证与最小投影。** Given完成生产构建，When扫描客户端源码、产物、网络响应和日志，Then不出现 Secret、用户令牌、Base Token、内部表/视图/字段 ID 或上游文件令牌；401/403、允许主机、回调鉴权和日志脱敏由服务端执行。证据：安全测试与产物扫描；责任方：安全/Web/QA。

**AC-SEC-02 写入安全。** Given任一测试开关关闭、记录不是 `TEST_`、缺少确认/幂等/版本/权限，When发起现有测试写 operation，Then前后端均拒绝且产生脱敏审计；重复、冲突和清理按合同执行。证据：服务端负向测试；责任方：Web/QA。

**AC-SEC-03 外部依赖双态验收。** Given任一 D01-D11 未解除，When QA 验收受影响项，Then记录具名阻塞、缺失制品和页面可验证阻塞态，不判定交付完成；Given依赖已解除，When运行正式端到端场景，Then以正式账号、数据或外部系统结果作为完成证据。责任方：依赖 Owner/QA。

**AC-DOC-01 合同文档一致性。** Given标识快照为 64 表/1311 字段且 registry 为 101 项，When生成或检查服务说明，Then数量和能力边界一致，并明确 36 个写 operation 仅为 `TEST_` 受控通道。证据：文档合同检查；责任方：技术文档 Owner/QA。
