# Product Requirements Document

## 1. Product Goal and Target User Value

将现有右上角非阻塞请求气泡替换为覆盖整个浏览器视口的 Loading。用户在前台请求尚未完成时获得明确、不可误操作的等待状态；请求进入任一终态后，页面自动恢复。

## 2. Facts, Open Assumptions, and Evidence

### Facts

- **Fact:** 用户于 2026-10-11 明确要求“修改为全页面 loading”。证据：当前任务 `task-brief.md` 与 `decision-log.md`。
- **Fact:** 当前实现使用右上角 `.request-loading-toast` 展示受跟踪前台请求。证据：前序任务 `DEH-UI-PARITY-REPAIR-20261008/design-handoff.md`。
- **Fact:** 前序批准设计明确保留非阻塞气泡并禁止全屏 Loading，本要求与旧批准基线相反。证据：`DEH-UI-PARITY-REPAIR-20261008/prd.md` State Inventory 和 `design-handoff.md` Implementation Contract。
- **Fact:** 当前请求状态基础设施已区分普通前台请求和 `silent` 请求。证据：`src/integration/request-status.js`、`src/integration/safe-proxy-client.js`。
- **Fact:** 当前测试环境部分请求可能持续超过 30 秒。证据：2026-10-11 测试环境复测结果。

### Open Assumptions Requiring Scope Approval

- **Assumption:** “全页面”指覆盖浏览器全部可见区域，包括顶部导航、侧栏和内容区，而非只覆盖主内容区。
- **Assumption:** 遮罩可阻止底层点击和滚动，但不主动移动键盘焦点，也不将遮罩实现为必须手动关闭的对话框。
- **Assumption:** 静默后台刷新仍不显示遮罩；只有进入全局前台请求计数的请求触发。

## 3. In Scope and Out of Scope

### In Scope

- 复用现有全局前台请求计数，显示单一全视口遮罩。
- 遮罩覆盖顶部导航、侧栏和业务内容，阻止底层点击与滚动。
- 居中显示加载动画、“正在处理 N 项请求”和辅助说明。
- 并发请求数量变化时更新文案，不重复创建遮罩。
- 全部成功、失败、取消或超时后自动关闭。
- 静默后台刷新不触发遮罩。
- 桌面、窄屏、移动 Web、200% 缩放和减少动画模式适配。
- 添加回归测试，防止恢复为右上角气泡或发生无法关闭。

### Out of Scope

- 后端缓存、飞书读取、轮询、超时和任务状态修复。
- 改变哪些请求属于前台请求或静默刷新。
- 修改业务页面结构、局部状态、接口合同、权限、审批、上传、幂等和审计。
- 恢复“首次同步”“数据缺失”或“数据更新时间”提示。
- 部署、发布、推送、合并。

## 4. Primary User Flow

1. 用户进入任一已授权业务页面或触发一个受跟踪前台操作。
2. 第一个前台请求开始时，全视口 Loading 立即出现。
3. Loading 覆盖顶部导航、侧栏与内容区，底层不可点击和滚动。
4. 并发请求增加或减少时，同一遮罩更新请求数量。
5. 只要仍有一个前台请求未进入终态，遮罩继续显示。
6. 最后一个请求成功、失败、取消或超时后，遮罩自动关闭。
7. 页面按照既有 normal、empty、error、disabled 或 permission-denied 状态继续展示。

## 5. State Inventory

- **Success:** 请求计数归零，遮罩移除，页面按既有成功内容展示。
- **Loading:** 请求计数大于零，全视口遮罩可见，底层交互和滚动被阻止。
- **Empty:** 遮罩关闭后，由页面既有空态展示；Loading 不冒充空态。
- **Error:** 请求失败后必须结束对应请求计数；最后一个请求结束即关闭遮罩，由既有错误边界展示错误和重试。
- **Disabled:** 遮罩可见期间底层控件不可触发；遮罩关闭后恢复原有禁用规则。
- **Permission-dependent:** 401/403 等终态必须关闭遮罩，再进入现有授权或无权限状态，不得永久遮挡。

## 6. Explicit Non-goals / Things Not to Do

- 不通过固定延时隐藏 Loading。
- 不在每个请求上创建多个叠加遮罩。
- 不让静默刷新触发遮罩。
- 不在遮罩中展示首次同步、数据缺失、技术错误码或刷新按钮。
- 不为实现遮罩修改后端协议或业务页面数据逻辑。
- 不把遮罩做成需要用户手动关闭的弹窗。

## 7. Acceptance Criteria

### AC-1 全视口覆盖

**Given** 任一受跟踪前台请求正在进行，  
**When** 全局请求计数大于零，  
**Then** 页面只显示一个固定于视口的 Loading 遮罩，覆盖顶部导航、侧栏和内容区，不再显示右上角气泡。

### AC-2 阻止底层操作

**Given** 全页面 Loading 正在显示，  
**When** 用户尝试点击、滚动或重复提交底层页面，  
**Then** 底层操作不会被触发，页面背景不滚动。

### AC-3 自动结束

**Given** 一个或多个前台请求正在进行，  
**When** 最后一个请求成功、失败、取消或超时，  
**Then** 全局请求计数归零，Loading 自动移除，页面进入既有终态，不需要刷新或手动关闭。

### AC-4 并发合并

**Given** 同时存在多个受跟踪请求，  
**When** 请求数量发生变化，  
**Then** 仍只有一个遮罩，文案显示当前请求数量，并在全部结束前保持可见。

### AC-5 静默刷新

**Given** 仅有 `silent` 后台刷新正在执行，  
**When** 页面已有可用内容，  
**Then** 不显示全页面 Loading，页面继续可操作。

### AC-6 可访问性与响应式

**Given** 用户使用桌面、窄屏、移动 Web、200% 缩放或减少动画模式，  
**When** Loading 显示，  
**Then** 加载文案保持可读、无遮挡与横向溢出；状态被礼貌播报；不抢夺焦点、不形成焦点陷阱；减少动画模式停止旋转动画。

### AC-7 业务回归

**Given** 请求结束并关闭遮罩，  
**When** 用户继续使用登录、筛选、申请、上传、审批或其他现有功能，  
**Then** 路由、数据、权限和业务动作与改造前保持一致。

## 8. Open Questions and Decisions Needed for Scope Approval

1. 确认全页面遮罩覆盖顶部导航、侧栏和内容区。
2. 确认遮罩期间禁止所有底层操作与页面滚动，即使某些区域已有缓存数据。
3. 确认静默后台刷新不显示遮罩。
4. 接受当前后端慢请求可能使整个页面被遮罩数十秒；该后端问题不在本任务处理。
