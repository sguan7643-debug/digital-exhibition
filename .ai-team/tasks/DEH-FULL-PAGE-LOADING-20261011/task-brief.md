# Task Brief

## Goal
把当前右上角“正在处理请求”气泡改成覆盖整个浏览器视口的全页面 Loading，直到受跟踪前台请求全部进入终态。

## User
等待数智展厅真实数据加载或前台业务操作完成的 Web 用户。

## Mode
现有 Vue Web 项目增量修改。

## Platforms
仅 Web；桌面、窄屏和移动浏览器响应式覆盖。未声明 uni-app 或原生移动端。

## Scope
- 复用现有全局前台请求计数。
- 全视口固定遮罩、居中动画和请求数量文案。
- 遮罩期间阻止底层页面交互和滚动。
- 所有成功、失败、取消、超时终态自动关闭。
- 静默后台刷新继续不触发可见 Loading。
- 新增行为、响应式与可访问性回归测试。

## Out of Scope
- 后端缓存、同步任务与超时修复。
- 业务接口、权限、审批、上传、幂等与审计变更。
- 恢复首次同步、数据缺失或更新时间提示。
- 部署、发布、合并或推送。

## Success Metric
前台请求期间始终只有一个全页面 Loading；底层不可操作；全部请求结束即自动恢复；静默刷新无可见遮罩。

## Deadline
立即处理，未指定发布期限。

## Risk
高风险：当前测试环境部分读取可持续数十秒，全页面遮罩会在此期间阻断全部操作。产品负责人已明确提出全页面 Loading，本任务仍要求在范围与设计门禁中显式确认该取舍。

## Dependencies
- 现有 `request-status` 前台请求计数必须保持正确收敛。
- 现有请求所有终态必须执行 `endRequest`，否则全页遮罩可能无法关闭。
- 继承现有 Vue 外壳、响应式样式和真实业务数据逻辑。
