# Task Brief

## Goal
完成数智产品展厅 Web 的系统整体 POC 收口，用同一套可复验命令和真实预发布链路证明当前系统可用。

## User
产品负责人、业务验收人员和负责预发布联调的 Web 研发测试人员。

## Mode
既有 Vue Web 项目。

## Platforms
仅 Web；不声明移动端或 uni-app。

## Scope
- 修复全量自动化和浏览器回归中的当前阻断。
- 复验构建、无模拟数据、UI 同步、真实飞书读取和受控 `TEST_` 写入边界。
- 复验应用上线真实上传、审批、状态同步、申请列表/详情和批准后投影。
- 汇总代码审查、功能 QA、兼容性 QA 和发布就绪证据。

## Out of Scope
- 生产部署、发布、推送、合并。
- 非 `TEST_` 数据变更或破坏性清理。
- 外部系统本体建设和移动端开发。
- 把外部输入缺失的生产能力包装为 POC 成功。

## Success Metric
全量单元/交互/集成测试、生产构建、无模拟数据、UI 同步和已授权浏览器多尺寸路由回归全部通过；关键真实业务闭环可复验；最终 QA 阻断为 0。

## Deadline
尽快完成当前预发布 POC 验证。

## Risk
高风险。风险来自真实飞书预发布写入、OAuth 会话、跨任务脏工作区和大量历史断言；Team Lead 负责限制到 `TEST_` 数据、精确目标、幂等重放和证据化回归。

## Dependencies
- 本地开发服务和已登录飞书浏览器配置可用。
- `.env.local` 中服务端飞书凭证和 POC 写入门禁有效，但不得输出秘密。
- 现有专项任务的已批准成果可作为输入，不能替代本任务的独立回归。
