# Task Brief

## Goal

在飞书多维表格继续作为唯一业务数据源的前提下，完成后端读取生命周期、缓存/同步性能和业务数据合同修复，使业务页面自动取得正式、完整、具名且按权限隔离的数据。

## User

- 已登录并获授权访问数智展厅的 Web 业务用户。
- 验证真实飞书数据、权限隔离、读取性能和部署可回滚性的测试/运维人员。

## Mode

现有 Vue Web 项目的后端服务与测试修复；前端代码不在本任务范围。

## Platforms

- Web：Vue 前端的 Node 后端接口。
- Mobile：未声明。

## Scope

1. 构建/测试导入不得启动飞书预热；仅 Node 服务启动后预热。
2. 缓存、五秒交接、后台同步、任务合并、状态轮询、热读复用和资源级故障隔离。
3. APP-001/002/003 人员与部门名称批量投影。
4. COM-004 当前用户联系方式与权限范围。
5. COM-005 正式字典过滤与业务负责人确认基线。
6. WB-003 身份优先、空统计/待办和 userId 隔离。
7. FAV-002/003/004 当前用户 APP 收藏及稳定版本合同。
8. APP-005 正式申请、稳定标识、权限/审批/幂等/审计。
9. MAT-002/003 文件标识和同源安全下载。
10. 自动化验证、纯后端部署包、SHA-256、部署/验证/回滚命令。

## Out of Scope

- 不修改前端源码或根 `dist`。
- 不引入 Redis/数据库，不替换飞书。
- 不生成假姓名、假联系方式或测试字典。
- 不在未获业务确认时擅自定义正式业务域字典。
- 不直接部署或操作服务器、飞书权限和正式业务数据。

## Success Metric

- build/配置导入/测试导入触发飞书请求数为 0。
- 冷页面无需手动刷新；常用读取至少 90% 首次 5 秒内完整返回；热缓存近即时。
- 超过五秒只返回有效同步任务，轮询不重跑原 operation，第二次刷新命中缓存。
- 正常读取不返回“正式飞书数据正在首次同步”等业务结果。
- 人员、负责人、开发者、部门均展示正式名称，不展示内部编码。
- COM-004、WB-003、收藏、应用申请、素材下载在真实授权账号下完成并满足隔离与安全合同。

## Deadline

尽快完成。正式业务域字段与选项取决于闫瑾提供或确认可执行字典基线。

## Risk

高风险。涉及身份/联系方式、权限隔离、审批幂等审计、附件下载、飞书限流与现有缓存恢复链路。由后端工程和 QA 通过最小权限、批量投影、六维隔离键、结构化失败、资源限制与回滚包控制风险。

## Dependencies

- `DEH-SERVER-CACHE-RECOVERY-20261010` 的缓存/任务实现与未关闭代码审查发现；不能直接复用其当前部署包作为发布候选。
- 飞书应用对人员、部门、手机号、邮箱、附件下载所需的实际权限。
- 业务负责人闫瑾确认的正式业务域字段与选项。
- 真实授权测试账号和测试环境用于最终联系人、跨用户隔离、申请/收藏/下载验收。
